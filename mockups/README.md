# UI demo (Native design)

A clickable, standalone demo of the redesigned app: Wallet, Pay, Scan, Deals, and Rewards. It runs on frozen API responses in `src/data/`, so it needs no backend, and nothing in `frontend/` imports it.

## Run it

```bash
cd mockups
npm install
npm run dev        # http://localhost:5190
```

On a computer it shows inside an iPhone frame. Double-click the frame's right side button to open Pay, like Apple Pay.

## Open it on your phone

1. Put the phone and computer on the same Wi-Fi.
2. Run `npm run dev` and copy the `Network:` URL it prints, e.g. `http://192.168.1.23:5190`.
3. Open that URL in Safari (iPhone) or Chrome (Android). On a phone the app fills the screen.
4. Optional: Share → **Add to Home Screen** for a full-screen launch.

The demo starts at Trader Joe's. Tap the store chip to pick another store, or the × to leave it. Pay with the best card to see the streak and cash-back celebration.

`?all` in the URL also shows the four earlier design directions.

## Checks

```bash
npm run typecheck
npm run build
npm run shots -- 1            # walks the demo in Chrome, writes artifacts/native/ + report.json
PHONE=1 npm run shots -- 1    # same at iPhone size, writes artifacts/native-phone/
```

`npm run shots` needs the dev server running. The screenshots aren't committed; rerun it to regenerate them.

## Demo data

`src/data/missed.json` is a month of purchases by someone who uses the app: 42 purchases, 89% of possible rewards captured, $265 saved with codes. It's generated by running each purchase through the backend's own engine:

```bash
cd backend && .venv/bin/python ../mockups/scripts/seed_history.py
```
